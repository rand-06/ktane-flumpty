# Техническое задание: модуль «Flumpty» (KTANE)

## 1. Общее описание

Модуль-босс. Игрок должен отслеживать перемещения Фламти между модулями бомбы, определять его текущую позицию и вовремя «фотографировать» его камерой при атаке. При провале — взрыв бомбы (в обычном режиме) или страйк (в режиме Showdown).

---

## 2. Базовые сущности и состояния

### 2.1. Модуль «Flumpty»
- Является модулем KTANE.
- Всегда считается контролируемым Фламти.
- Может быть несколько экземпляров на одной бомбе (см. п. 9).
- На модуле отображается ID (для нескольких экземпляров).

### 2.2. Активность
- Фламти неактивен, пока не выполнено хотя бы одно из условий:
  - решено ≥ 5 других модулей;
  - Фламти — последний нерешённый модуль, и бомба запущена с < 5 модулями.
- При активации: мерцание света + звуковой сигнал.
- После активации Фламти действует немедленно, затем после каждого решения неигнорируемого модуля.

### 2.3. Захват модулей
- Фламти может захватывать решённые модули: они становятся полностью чёрными, иногда глитчуют.
- Игрок должен запоминать, какими были эти модули.
- Захваченные модули могут освобождаться.
- Новые захваты: длинный низкий тон.
- Освобождение: звук выключения модуля.
- Одновременный захват и освобождение: хихиканье.
- Новые захваты мерцают интенсивнее старых.

---

## 3. Генерация movement seed

### 3.1. Формирование битовых строк
Для каждого модуля, захваченного Фламти:
1. Взять имя модуля, удалить все не-английские символы. Если строка пуста — заменить на `0`.
2. Бесконечно повторять имя (конкатенация сама с собой).
3. Преобразовать в бесконечную бинарную строку: каждый символ → base-36 → mod 2.
4. Для модуля «Flumpty» — всегда включать его строку.

### 3.2. Комбинирование
- Если последняя цифра серийного номера нечётная: XOR всех строк.
- Иначе: NOT(XOR всех строк).
- Результат — movement seed.

### 3.3. Обновление seed
- При захвате новых модулей: добавить их битовые строки, пересчитать seed.
- При освобождении: удалить их строки, пересчитать seed.
- **Всегда** сначала пересчитать seed, потом оценивать действие Фламти.
- Если ранее было встречено `1110` — инвертировать все биты при пересчёте.

---

## 4. Интерпретация movement seed

Фламти стартует на модуле «Flumpty».

### 4.1. Чтение битов
Взять первые 3 бита → параметр из Таблицы 1.

**Таблица 1: Параметры (стандартный порядок)**

| Биты | Параметр |
|------|----------|
| 000 | Solve order (от раннего к позднему)* |
| 001 | Алфавитный порядок (0→Z)** |
| 010 | Дата публикации (от ранней к поздней)*** |
| 011 | Time Mode score (по возрастанию)**** |
| 100 | TP score (по возрастанию)**** |
| 101 | Алфавитный порядок последней буквы, затем предпоследней и т.д. (0→Z)** |
| 110 | Переведённое base-36 значение имени модуля (по возрастанию)* |
| 111 | Нет движения; инверсия строки или атака |

- `*` «Flumpty» всегда в конце.
- `**` Удалить символы вне base-36. Если пусто — заменить на `0`.
- `***` Если дата не указана — использовать сегодняшнюю.
- `****` Если TP score нет — использовать `0`.

### 4.2. Если первые 3 бита ≠ 111
1. Отсортировать модули, занятые Фламти, по параметру.
2. Следующий бит:
   - `0` — стандартный порядок;
   - `1` — обратный порядок.
3. При равенстве: перейти к следующему параметру в таблице (пропуская последнюю строку, при необходимости — по кругу). Разрешать по первому различающемуся параметру с тем же порядком.
4. Следующие 3 бита → двоичное → десятичное → N. Прибавить 1.
5. Фламти перемещается на N-й модуль в списке, начиная с текущего.
6. Удалить 7 бит из seed и битовых строк.

### 4.3. Если первые 3 бита = 111
- Следующий бит `0`: инвертировать весь movement seed. Удалить 4 бита.
- Следующий бит `1`: переход к разделу «Атака» (п. 6).

---

## 5. Обработка новых/освобождённых модулей

- При захвате: добавить битовые строки новых модулей **под** текущими, пересчитать seed.
- При освобождении: удалить их строки, пересчитать seed.
- Учитывать флаг инверсии от `1110`.

---

## 6. Разрешение атаки

### 6.1. Триггер
Первые 4 бита movement seed = `1111`.

### 6.2. Действия игрока
- Кликнуть по модулю, где сейчас скрывается Фламти, до решения любых других модулей.
- Успех: Фламти объявляет игрока победителем и уходит (в обычном режиме).
- Ошибка (неверный модуль / клик по занятому модулю вне атаки): страйк + предложение войти в stage recovery mode.

### 6.3. Stage recovery mode
- Фламти возвращается на исходный модуль «Flumpty», освобождает все занятые модули.
- Нажатие на Flumpty, когда последняя цифра таймера ≠ последней цифре серийного номера: показать состояние бомбы после каждого решения. Занятые модули кратко мерцают вместо мгновенного почернения.
- Выход: нажатие на Flumpty, когда последняя цифра таймера = последней цифре серийного номера. Фламти возвращается в предыдущее состояние.
- Режим доступен в любой момент, даже вне атаки.

### 6.4. Провал
- Если решён другой модуль до обработки атаки: смерть, взрыв бомбы.

### 6.5. Особый случай: Фламти — последний модуль
- Если `1111` не встречено: после решения последнего модуля Фламти делает финальное перемещение и атакует.
- Процесс решения идентичен.

### 6.6. TP-режим (Twitch Plays)
- Решённые модули нельзя взаимодействовать.
- Ввести имя модуля, на котором находится Фламти, в любой модуль «Flumpty» — он решится.
- Если есть другой модуль с тем же именем: добавить номер (с 0) по позиции на корпусе (например, `Flumpty 0`).

## 7. Hard Boiled Mode

### 7.1. Условие входа
Автоматически, если на одной бомбе с Фламти присутствуют **все** модули:
- egg
- perspective eggs
- yoshi egg
- breakfast egg
- scramboozled eggain
- devilish eggs

(Фламти **не** считается egg-модулем.)

### 7.2. Отличия
- Генерация seed и перемещение — идентичны обычному режиму.
- Фламти **не** решается после первой отбитой атаки.
- После следующего решения двигается как обычно и остаётся до конца бомбы.
- Может атаковать многократно.
- Все 6 egg-модулей **всегда** под контролем Фламти, даже до решения. Их битовые строки и сами модули учитываются при определении движения.
- Если Фламти пытается атаковать с нерешённого egg-модуля: он вместо этого перемещается на следующий решённый и занятый модуль по параметру, использованному для попадания на этот egg-модуль. Новый модуль считается текущей позицией для следующего шага.

### 7.3. Дублирование
- При попадании на egg-модуль (решённый или нет) Фламти всегда дублируется.
- Новый Фламти — как отдельный модуль «Flumpty» со стартовой позицией на текущем egg-модуле.
- При следующем решении: первые 4–7 бит — первому Фламти, следующие 4–7 — второму и т.д.
- Новый Фламти может атаковать и дублироваться.
- Максимум одно дублирование на egg-модуль.
- Итого: не более 7 Фламти (плюс дополнительные за каждый дополнительный модуль «Flumpty»).
- Лимит одно дублирование на egg-модуль — **общий для всех** Фламти.

### 7.4. Showdown
- Когда Фламти — последний нерешённый модуль: после решения предпоследнего модуля он захватывает большую часть бомбы.
- Даётся ~2.5 минуты на: расчёт нового seed, оценку позиций всех Фламти, клик по нужным модулям.
- Звуки и визуальные эффекты могут отвлекать, но не влияют на решение.
- Успех: Фламти признаёт поражение.
- Провал: страйк за каждого неостановленного Фламти, бомба **не** взрывается.
- В настройках мода можно включить детонацию при провале.
- Настройки мода позволяют принудительно включать/выключать Hard Boiled Mode независимо от наличия egg-модулей.

---

## 8. Множественные модули «Flumpty»

- Общий movement seed для всех.
- Биты обрабатываются последовательно: первые 7 — первому, следующие 7 — второму и т.д.
- Порядок действий — по ID модуля: меньший ID двигается раньше.
- Все Фламти активируются одновременно.
- Если несколько Фламти атакуют с одного модуля одновременно: одного клика достаточно для всех.

## 9. Визуальные и звуковые эффекты

| Событие | Эффект |
|---------|--------|
| Активация | Мерцание света + звуковой сигнал |
| Захват модуля | Длинный низкий тон |
| Освобождение модуля | Звук выключения модуля |
| Одновременный захват и освобождение | Хихиканье |
| Новый захват | Интенсивное мерцание |
| Атака | Визуальное/звуковое предупреждение (по усмотрению) |
| Showdown | Отвлекающие звуки и визуальные эффекты |
